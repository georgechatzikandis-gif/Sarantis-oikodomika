# Σαράντης — Οικοδομικά Υλικά

Animated one-page website (static HTML/CSS/JS, no build step). Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).

## Structure
- `index.html` — page content (Greek)
- `css/style.css` — theme (black / grey / white / yellow) and animations
- `js/main.js` — loader, scroll reveals, counters, parallax, particle canvas, cursor, magnetic buttons, card tilt, mobile menu, contact form
- `assets/` — logo mark (`mark.svg`), original logo (`logo.png`), storefront photos
